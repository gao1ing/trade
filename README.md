# 贸易业务示例

## 运行环境

JDK 17、Maven、Spring Boot 3.5.7、MyBatis-Plus 3.5.14。业务数据存储在 MySQL，汇率快照和刷新锁使用 Redis。

## 代码说明

1. **库存数据一致性**：提交出库单时，按库存明细扣减并记录流水。作废或重新生成时，根据原扣减记录恢复库存。库存不足或乐观锁更新失败时，Spring 事务回滚本次操作。
2. **产品图片批量同步**：用线程池并行处理三类产品图片，每页最多 500 条。单条失败后继续处理其他记录，每批默认最多等待 30 秒。
3. **汇率查询与缓存刷新**：查询时直接读取 Redis 快照。后台每 30 分钟尝试刷新，用 Redisson 锁避免重复抓取。请求超时或数据校验失败时保留上次成功获取的汇率。
