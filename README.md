# 贸易系统：出库库存、产品图片与汇率查询

## 1. 环境

- 开发与构建：JDK 17、Maven。
- 后端框架：Spring Boot 3.5.7、MyBatis-Plus 3.5.14。
- 数据库：MySQL，默认连接本机 3306 端口的 `tradeexample` 库。
- 缓存：Redis，默认使用本机 6379 端口，保存汇率快照。

## 2. 代码说明

1. **库存数据一致性**：提交出库单时，按库存明细扣减数量并记录流水。作废或重新生成已提交的出库单时，按原扣减记录把数量加回对应批次。库存不足或其他请求已修改同一条库存时，整笔操作回滚。
2. **产品图片批量同步**：用线程池并行同步自有产品、客户产品和配件的图片，每批最多 500 条，默认最多等待 30 秒。单张图片失败后记录原因，继续处理其他图片，失败记录可以单独重试。
3. **汇率查询与缓存刷新**：查询时直接读取 Redis 中的汇率。后台每 30 分钟尝试刷新，用 Redisson 锁保证同一时间只有一个任务抓取报价。请求超时或报价校验失败时，继续使用上次成功获取的汇率。
